# もりのまもりびと（作り直し版） — ゲーム仕様書（下書き）

Oct 19, 2026 · 下書き

## 概要

この文書は Claude Code が「もりのまもりびと」を作り直すための仕様書で、リポジトリ `family-game` の `mori/CLAUDE.md` として置く。リポジトリ全体の決まりはルートの `CLAUDE.md` に書き、本書はそれに従う。

- ジャンル：2D見下ろし型の拠点防衛アクション。木を切って木材を集め、とうとかべを建てて、おうちを敵から守る。iPad の Safari で遊ぶ Web ゲーム
- 作り直しの狙い：遊びの土台（木を切る → 建てる → 守る）は今の版のまま残し、次の3つを良くする
  - 見た目：図形で丁寧に描き、動きと演出を作り込む
  - ボリューム：とう・敵の種類を増やす、ステージをまたいだ成長、物語と会話
  - 直しやすさ：数値・ステージ・会話をデータに分け、自動テストで確かめられるようにする
- 対象：小学校高学年。漢字は小学校で習う範囲、難しい語はふりがなを付ける（今の版はひらがなだけだったが、作り直し版から変える）
- 規模：8ステージ＋むげんモード。1ステージ10分前後
- 実装の原則：とう・敵・ステージ・会話は JSON データで定義し、コードを変えずに調整できること
- この文書にない細部は Claude Code の判断で決めてよい。決めた内容は `docs/decisions.md` に1行ずつ追記する

## 今の版（作り直し前）の要点

今の版は `mori/index.html` の単一 HTML（Canvas 2D、742行）。作り直しの間は `legacy/index.html` に移して参考にする。引き継ぐ遊びは次のとおり。

- 仮想スティックで歩く。木のそばにいると自動で木を切り、敵が近いと自動で斧で攻撃する
- 木材は持てる数に上限がある（かばんで増える）。建設地点の円に立つと、木材を少しずつ払って建てる
- 建てられるもの：とう（建てたときに3種類から選ぶ、Lv3まで）、かべ（おうちを囲む8区画、木→石）、おの（木を切る速さと攻撃）、かばん（持てる数）、領地を広げる旗（木と建設地点が増える）
- 準備時間のあとに敵がウェーブで来る。「すぐ よぶ」で準備を早めに切り上げると経験値のボーナス
- 戦闘中にレベルが上がると、強化を3つから1つ選ぶ（ステージが終わるとリセット）
- 全ウェーブを守り切るとクリア。おうちの HP が0で負け。おうちの残り HP で★1〜3
- 難易度3段階（かんたん／ふつう／むずかしい）、むずかしいでクリアすると王冠
- 敵：スライム、小スライム、ゴブリン、こうもり（かべを飛び越える）、オオカミ（速い）、よろいの騎士（たいほう以外は半減）、分裂スライム、ボス、まおう（スライムを呼ぶ）
- とう：やのとう（空にも当たる）、たいほうのとう（範囲・よろいに強い・空に届かない）、こおりのとう（遅くする）

## 世界観と物語

森の村に住む見習いの「まもりびと」が主人公。森を枯らしながら広がる「まおう」の軍勢から、8つの森の村を順に守っていく。こわい描写は避け、倒した敵は煙になって消える表現にする。

| 名前 | 役割 | ゲーム内の扱い |
| --- | --- | --- |
| 主人公（名前は未決） | 見習いのまもりびと | プレイヤー操作 |
| 森の精霊（名前は未決） | 案内役。主人公にまもりびとの技を教える | 会話の相棒。戦場には出ない |
| 各ステージの村人 | 守る村の住人 | 開始とクリアの会話に出る |
| まおうの手下（ボス） | ステージ3・5・7の敵将 | ボスとして登場 |
| まおう | 森を枯らす元凶 | ステージ8の最後の敵 |

会話は1ステージあたり、開始・ボス出現・クリアの3回で、各3行以内。会話中はゲームを止め、タップで進める。会話の文章は `data/story/stageN.json` に置く。

| 3 | 雪の森 | 雪 | こおりのとう、空を飛ぶ敵、最初のボス |

各ステージの地形・建設地点・ウェーブ構成は `data/stages/stageN.json` に書く。

## 基本ルール

操作は仮想スティックだけにする。ボタンは「すぐ よぶ」「ひとやすみ」「音」の3つ。

- 移動：画面をなぞる仮想スティック（置いた位置が原点、指に追従）。PC では WASD／矢印キー
- 木を切る・攻撃：自動。近くに敵がいれば攻撃、いなければ近くの木を切る
- 建設：建設地点の円に立つと、木材を少しずつ払って建てる。途中で離れても払った分は残る
- 勝利：全ウェーブを守り切る。ボスのいるステージは最後のウェーブでボスを倒す
- 敗北：おうちの HP が0
- 評価：おうちの残り HP で★1〜3。むずかしいでクリアすると王冠
- HUD：木材（持っている数／上限）、レベルと経験値、ウェーブ数、おうちの HP、敵の残り数、画面外の敵の方向を示す矢印
- 難易度：かんたん／ふつう／むずかしいの3段階。敵の HP・数・速さ、おうちの HP、準備時間の倍率を変える（今の版と同じ考え方）

## とうと敵

とうは3種類から5種類に増やし、Lv3 で2つの道から1つを選ぶ「分かれ道」を入れる。数値は今の版の値を出発点に `data/towers.json` と `data/enemies.json` に置き、相性（空に届くか、よろいに強いかなど）もデータで持たせる。

とう（案）

| とう | 役割 | Lv3 の分かれ道（案） |
| --- | --- | --- |
| やのとう | 単体・空に当たる | 連射 ／ 遠くまで届く |
| たいほうのとう | 範囲・よろいに強い・空に届かない | 大爆発 ／ 燃える地面を残す |
| こおりのとう | 遅くする | 広い範囲を遅くする ／ 一瞬こおらせる |
| かみなりのとう（新） | 近くの敵に連鎖する | 連鎖の数を増やす ／ 空の敵に強い |
| ちゆのとう（新） | 近くのかべとおうちを少しずつ直す | 直す速さ ／ かべを固くする |

敵（今の9種類に足すもの・案）

| 敵 | 特徴 | ねらい |
| --- | --- | --- |
| たて持ち | 正面からの矢を防ぐ | とうを周りに散らして置かせる |
| もぐら | かべの下をくぐる | かべだけに頼らせない |
| 木こりゴブリン | 森の木を切り倒して持ち去る | 木材集めに緊張感を出す |
| いやしの魔法使い | 近くの敵を回復する | 狙う順番を考えさせる |

## 成長

成長は2つの層にする。

戦闘中の成長（今の版と同じ）

- 木を切る・敵を倒すと経験値。レベルが上がると強化を3つから1つ選ぶ
- ステージが終わるとリセットされる

ステージをまたいだ成長（新）

- ステージをクリアすると、評価（★）に応じて「森のめぐみ」（名前は未決）がもらえる。クリア済みのステージを遊び直しても少しもらえる
- ステージを選ぶ画面の前に「まもりびとの家」の画面を置き、めぐみで次の3系統を強くする

| 系統 | 中身（案） |
| --- | --- |
| まもりびと | 歩く速さ、斧の攻撃、持てる木材の数、木を切る速さ |
| とう | 新しいとうの解放、とうの攻撃、建てる木材が安くなる |
| おうち | おうちの HP、かべの固さ、最初から持っている木材 |

- 振り分けは「まもりびとの家」でいつでもやり直せる（高学年でも気軽に試せるように）
- 新しいとうは、ステージで初登場したあと、ここで解放すると次から使える

## セーブ

- localStorage に自動保存する（クリア済みステージ、★と王冠、めぐみと振り分け、解放したとう、難易度、むげんモードの最高記録）
- キーは `mori3_` で始める（ルートの CLAUDE.md の決まり）。作り直し版のセーブは `mori3_save` とし、今の版の `mori3_prog` は読まない（はじめから遊ぶ）。古いキーは消さずに放っておく
- セーブは1枠。タイトルの「はじめから」で消せる

## 見た目

画像は使わず、Phaser.Graphics の図形で丁寧に描く。あとから画像素材に差し替えられるよう、描画はビュー（`views/`）に分ける。

- 立体感：影、輪郭、2〜3段の色で丸みを出す
- 動き：歩く・木を切る・攻撃の動き、木が揺れて倒れる、とうが建つときに弾む
- 演出：攻撃が当たったときの白い点滅と小さな画面の揺れ、木くずや煙の粒、ウェーブ開始とクリアの大きな文字
- ステージごとの雰囲気：地面と木の色、雪・落ち葉・火の粉などの天気、夜の暗さ
- 文字は大きく、縁取りを付けて背景に埋もれないようにする

## 技術方針

ジャンヌと同じ Phaser 3 ＋ TypeScript ＋ Vite で作る。iPad の Safari で動き、ホーム画面に追加するとフルスクリーンで遊べる。

- 外部サーバーとの通信、広告、アカウント登録は入れない。保存は localStorage だけ
- 画面は縦横どちらでも動くようにし、ボタンはセーフエリアを避けて置く
- アプリを切り替えたら自動で一時停止し、戻ったら音を鳴らし直す（今の版の iPad 対応を引き継ぐ）
- ゲームの計算は Phaser から切り離して `systems/World.ts` にまとめ、ヘッドレスで自動プレイできるようにする（ジャンヌと同じ方式）
- 公開はリポジトリ共通の GitHub Actions（`.github/workflows/deploy.yml`）で行う。`vite.config.ts` の `base` は `'/family-game/mori/'`。`dist/` はコミットしない
- 作り直し版に全ステージがそろうまで（マイルストーン6まで）、公開サイトの `/mori/` には今の版（`legacy/index.html`）を置き続け、作り直し版は `/mori/next/` で試す。ステージが足りないうちに入れ替えると、今の版で遊べていたステージ2〜8とむげんモードが遊べなくなるため。切り替えは deploy.yml の配置手順で行う
- 性能目標：敵100体＋とう20基で60fps。対象機は iPad Air 第4世代

ステージ定義（JSON）に持たせるもの

- 見た目：テーマ（地面・木・天気の色）
- 地形：おうちの位置、木の配置（密度と除外範囲）、領地の広さの段階、障害物
- 建設地点：種類、位置、領地のどの段階で現れるか
- ウェーブ：回数、各回の敵の種類と数、来る方向、ボス、準備時間
- 会話のきっかけ：開始、ボス出現、クリア

## 開発の進め方

7つのマイルストーンを順に進め、各段階の終わりに iPad で触って確かめる。1つ終わるごとにコミットする。

1. 土台：Vite のひな形、移動、木を切る、木材を運ぶ、建設地点、ヘッドレスの World と自動テスト。deploy.yml に mori のテストとビルドを足す（公開は今の版のまま）。確認：iPad での操作感
2. 守りの核：おうち、敵のウェーブ、とう3種、かべ、おの・かばん、領地を広げる、戦闘中のレベルアップ。ステージ1を JSON から作る。確認：今の版と同じ遊びができること
3. 見た目：描画と演出の作り込み。確認：今の版より楽しそうに見えること
4. とうと敵を増やす：とう5種と分かれ道、新しい敵4種。確認：置き方で結果が変わること
5. ステージをまたいだ成長とセーブ：まもりびとの家、めぐみ、解放。確認：アプリを閉じても続きから遊べること
6. 物語と全ステージ：会話、8ステージ、ボスとまおう、難易度、むげんモード。確認：子どもが1人で最後まで遊べること。確認できたら、ユーザーの OK を取って公開の `/mori/` を作り直し版に切り替える
7. 仕上げ：効果音、バランス調整、画面の文字の見直し

テスト

- `vitest` で、ダメージ計算、とうの狙い、建設の支払い、経験値と強化、成長の計算、セーブの読み書きをユニットテストする
- 各マイルストーンで、ボットが主人公を動かす自動プレイを回し、ステージを最後まで通せることと、エラーが出ないことを確認する
- 実機テストは iPad で子どもが遊び、感想と詰まった場所を `docs/playtest.md` に記録する
