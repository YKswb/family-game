# 実装中に決めたこと

## マイルストーン1（土台）

- 2026-10-19 ゲームの計算は Phaser から切り離した `systems/World.ts` にまとめ、vitest でヘッドレス自動プレイを回す（ボットは `tests/bot.ts`）。ジャンヌと同じ方式
- 2026-10-19 マイルストーン1で建てられるのは「おの」と「かばん」だけ。とう・かべ・領地を広げる旗はマイルストーン2で足す
- 2026-10-19 主人公の数値は `data/player.json`、木は `data/trees.json`、建物の値段と効果は `data/buildings.json` に置く（仕様書の一覧にないファイル）。数値は今の版と同じ
- 2026-10-19 画面は縦横どちらでも画面いっぱいに描く。ジャンヌのような固定比率＋余白ではなく、画面の大きさに合わせて Phaser のキャンバスを作り直し、戦場の拡大率は「短い辺に 580 が収まる」で決める（今の版と同じ見え方）
- 2026-10-19 Retina 対策はジャンヌと同じく、内部を DPR 倍（最大2）の画素で描いてキャンバスを 1/DPR に縮める。`?dpr=2` で上書きできる
- 2026-10-19 文字や HUD の拡大率は「短い辺 ÷ 420」を 1〜1.6 に収めた値（今の版と同じ）
- 2026-10-19 セーフエリアは index.html の見えない箱 `#safe` の padding（env(safe-area-inset-*)）から読む
- 2026-10-19 フォントは外部から読み込まない（外部通信をしない方針）。iPad にある「ヒラギノ丸ゴ」を使う
- 2026-10-19 アプリを切り替えると Phaser が自動で止まる。止まったときは仮想スティックを離した扱いにする
- 2026-10-19 建設地点のアイコンは当面は絵文字（🪓🎒）。マイルストーン3で図形に描き直す
- 2026-10-19 作り直し版は、今の版と入れ替えるまで公開サイトの `/mori/next/` に置く（CI で `--base /family-game/mori/next/` を付けてビルド）。`/mori/` には今の版（`legacy/index.html`）を置き続ける

## マイルストーン2（守りの核）

- 2026-10-19 敵・とう・難易度・強化の数値は、今の版の値をそのまま `data/enemies.json`、`towers.json`、`difficulty.json`、`upgrades.json` に移した
- 2026-10-19 ステージ1は今の版と同じ（スライムだけ、5ウェーブ、約3分）。10分の尺に合わせる調整はマイルストーン6で行う
- 2026-10-19 ウェーブの組み方（敵の種類と重み、出始めるウェーブ、方向の数、HP の伸び、出てくる間隔、大将）はステージの JSON の `waves` に持たせる。今の版でコードにあった「ステージ番号でHPや方向を変える」式は、各ステージの JSON の値に置き換える
- 2026-10-19 かべ（おうちを囲む8区画）はステージの JSON に書かず、`buildings.json` の `wall` から自動で作る。とう・おの・かばん・領地を広げる旗はステージの JSON に置く
- 2026-10-19 領地を広げると現れる建設地点は、ステージの JSON の `territory`（何段階目で現れるか）で指定する。旗の移り先は `moves`
- 2026-10-19 とうの種類とレベルアップの強化は World の `choices` に積み、答えが出るまで World は止まる（ヘッドレスのボットも答えてから進む）。続けてレベルが上がったときは、前の強化を反映してから次の選択肢を選ぶ
- 2026-10-19 とうの種類の選択、レベルアップの3択、ひとやすみ、結果の画面と、「ひとやすみ」「すぐ よぶ」のボタンは HTML で作り、ゲームの上に重ねる（文字が多く、今の版の見た目をそのまま使えるため）
- 2026-10-19 アプリを切り替えると「ひとやすみ」になる（今の版と同じ）
- 2026-10-19 かべの値札は、主人公が区画に 110 まで近づいたときだけ出す（今の版の 170 では、内側のとうの値札と重なったため）
- 2026-10-19 音を消すボタンは、効果音を入れるマイルストーン7で足す
- 2026-10-19 ステージ選びができるまでは、難易度を URL の `?diff=0`（かんたん）〜`?diff=2`（むずかしい）で選ぶ。既定はふつう
